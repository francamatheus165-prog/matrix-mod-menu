# Matrix Mod Menu v2.1.0

Matrix Mod Menu for MineFun.io, maintained under the Matrix Client project.

## Included

- Full Matrix Mod Menu v2.1.0 (16,344 lines)
- Canonical Tampermonkey installer
- Armor HUD assets and `client/armor/`
- Matrix badges
- Custom UI assets
- Minecraft and Bloxd texture packs
- Crosshairs
- Matrix client images and pet assets
- Steal A Pet data (`bot/stealapet.json`)
- Project font and documentation

## Installation

Install `matrix-mod-menu-v2.user.js` with Tampermonkey. The installer loads `matrix-mod-menu-v2.js` from the Matrix GitHub repository.

For a clean update, replace the entire repository contents with this package instead of mixing old and new asset folders.
