## ⚡ About

**Matrix Mod Menu v2** is a Tampermonkey mod menu developed for the Matrix Client.

It combines HUD mods, utilities, visual features, keybinds, texture packs, custom UI and other tools into a single interface.

> Made for MineFun players.

---

## 🧩 Features

### 🎯 Mods

- Zoom
- Crosshair
- Keystrokes
- FPS Counter
- CPS Counter
- Direction HUD
- Armor HUD
- Scoreboard
- Action Bar
- Damage Vignette
- Block Outline
- No Fog
- Hide Nametag
- Hide Particles
- Hide Arm
- Toggle Crouch
- Hurt Camera
- Clear Screen
- Texture Packs
- Custom UI
- BedWars Notifications
- Translator
- KDR Indicator
- GUI Scale
- Chat Emojis
- and more

### 🎨 Customization

Many mods can be customized with options such as:

- HUD position
- size
- colors
- opacity
- borders
- shadows
- keybinds
- themes
- individual mod settings
